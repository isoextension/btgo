# btgo
*A Go toolkit, feel free to contribute in any way.*
[Documentation](https://pkg.go.dev/github.com/isoextension/btgo)
## What?
btgo is a Go toolkit, made by [isoextension](https://linktr.ee/isoextension), but open to contribute under the GNU GPLv3
it includes such things as an ANSI code helper (package `ansi`), a logger library (package `logger`), and more things coming in the future (or contributed)
## Why?
i found the lack of a good Go modular toolkit and i needed a logging library. and then i decided to make things
